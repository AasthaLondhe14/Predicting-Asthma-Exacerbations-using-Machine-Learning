# Predicting-Asthma-Exacerbations-using-Machine-Learning
This project predicts asthma attacks using the k-Nearest Neighbors (k-NN) algorithm. It analyzes patient data—age, medical history, and environmental factors—to identify those at higher risk for worsening symptoms. The model demonstrates high accuracy, aiding healthcare providers in decision-making.
# Predicting Asthma Exacerbations Using Machine Learning

## Project Overview
This project uses the k-Nearest Neighbors (k-NN) algorithm to predict asthma exacerbations based on various patient factors. The aim is to identify patients at high risk of exacerbations and assist healthcare providers in preventive measures.
  
## Dataset
The dataset is sourced from [Kaggle: COPD-Asthma Patient Dataset](https://www.kaggle.com/datasets/jatinthakur706/copd-asthma-patient-dataset). The dataset was modified to fit the project requirements.

## Libraries Used
- `pandas`
- `scikit-learn`
